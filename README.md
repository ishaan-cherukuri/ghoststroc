# Ghoststroc

Two lamps. One shows what's there, the other shows what's holding it up. You
never get to see both at the same time.

A turn-based pixel roguelite for the browser. See `CLAUDE.md` for the full design.

**Status:** Stage 1, the fusion legibility prototype. One static room, two
fading channels, on-screen fade and palette controls.

```bash
npm install
npm run dev      # http://localhost:5173 (must be served, not opened as file://)
npm test
npm run build
```

AI disclosure: AI-generated: code. All art is hand-authored palette data; audio
will be synthesised with oscillators.
